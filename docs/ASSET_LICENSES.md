## 3. SIL Open Font License (OFL 1.1)

The offline fonts **Fredoka** (Primary Display font) and **Nunito** (Secondary UI font) are licensed under the SIL Open Font License Version 1.1:

- Permitted to be bundled and embedded within commercial software.
- Fonts operate 100% offline without remote network requests to Google Fonts API.
- Font binaries remain unaltered with original copyright metadata preserved.
